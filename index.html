Pengaturan AI

Hubungkan Gemini agar judul, narasi, dan caption bisa dibuat otomatis.

Panduan singkat
  1. Buka Google AI Studio. Kunjungi aistudio.google.com/apikey dan login dengan akun Google.
  2. Buat API key. Klik Create API key, lalu pilih project yang tersedia.
  3. Salin key. Copy key yang muncul, jangan dibagikan ke orang lain.
  4. Tempel dan simpan. Tempel di kolom di bawah, pilih model, lalu klik Simpan.
Key hanya disimpan di browser ini. Jika key tidak berfungsi, pastikan API Gemini sudah aktif untuk project tersebut.
Koneksi AI
Pilih dari saran, atau ketik ID model untuk Gemini 4 Hydrogen. Salin ID persisnya dari Google AI Studio (menu model), lalu tes koneksi.
Mengirim pesan uji ke Gemini memakai key dan model di atas.
